# Taking a Session In Without the Sync Box (Part 3a) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or
> superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for
> tracking.

**Goal:** Take in a session without the sync box: a manifest that does not list it, one that expects the rig's
record, and a listed sync box that never finishes, landed by a person's recorded command; and keep each staged
session on the clock that timed it.

**Architecture:** The manifest relaxes; the sentinel, discovery and verification learn the rig's `xcon/DONE`
and a set of systems a person landed the session without, read from the new `ingest.LandedWithout`; one
command records and evaluates; the clock's `choose_for` keeps a staged session on the sync box and refuses the
sync box for a session landed without it; the daily report shows both.

**Tech Stack:** Python 3.11/3.13, DataJoint 2.3.3 on MySQL (testcontainers in tests), pydantic, PyYAML.

**Spec:** `docs/superpowers/specs/2026-10-18-training-records-and-backup-clock-design.md`: §5, decisions 8 and
10, §8's part 3 ingest tests, §10 item 9; amendments 27 and 28 (before this plan) and 29-34 (Task 7's, made
while proving it). Part 3b, the NI as the clock, is a separate plan.

**Proven before written.** Every step below was run on a scratch branch and replayed from this plan's own
text to an identical tree: 16 mutation checks caught, and the full suite on both interpreters as
Task 7 states.

## Global Constraints

- **The sync box should run at every session; a session without it is still taken in** (the requester's
  ruling of 2026-10-18; spec §5). Part 3a takes it in and archives it; it is timed once part 3b or part 4 is
  built, and until then its events stage says why on each pass.
- **A listed sync box that never finishes waits for a person** (decision 10), never landing on its own after a
  wait; the person's command records who, why and when.

## The mutation checks


Each task names mutations as `[name, file, old, new, test]`. Save this helper once, outside the repository,
as `mutate.py`, and run it from the repository root with a task's list saved as JSON:
`.venv/bin/python /path/to/mutate.py /path/to/mutations.json`. Each mutation is applied alone, caches
cleared, its test run, and the file restored; every line must print `CAUGHT`, and `git status` must be
clean afterwards.

```python
"""Run the mutations in a JSON list [[name, file, old, new, test], ...] from the
current directory: each alone, caches cleared, restored after."""
import json, os, pathlib, shutil, subprocess, sys
root = pathlib.Path.cwd()
def clear():
    for cache in root.rglob("__pycache__"):
        if ".venv" not in cache.parts:
            shutil.rmtree(cache, ignore_errors=True)
for name, rel, old, new, test in json.loads(pathlib.Path(sys.argv[1]).read_text()):
    path = root / rel
    original = path.read_text()
    assert original.count(old) == 1, (name, "old text not found once")
    clear()
    path.write_text(original.replace(old, new))
    try:
        result = subprocess.run([sys.executable, "-m", "pytest", *test.split(), "-q", "-p", "no:cacheprovider",
                                 "-o", "faulthandler_timeout=1800"],
                                env={**os.environ, "PYTHONDONTWRITEBYTECODE": "1", "PYTHONPATH": str(root)},
                                capture_output=True, text=True)
    finally:
        path.write_text(original)
        clear()
    tail = result.stdout.strip().splitlines()[-1] if result.stdout.strip() else result.stderr[-200:]
    print(f"{name}: {'CAUGHT' if result.returncode else 'SURVIVED'} -- {tail}", flush=True)
```
