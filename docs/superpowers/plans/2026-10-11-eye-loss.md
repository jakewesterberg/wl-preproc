# Reading a Lost Eye Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `EyeQuality`'s tracking loss and blink rate, and the validity mask's `blink`, read the eye lost on a real OpenIrisDPI recording, where `DataQuality` is 100 on every frame and both now read zero.

**Architecture:**
- **One rule, `ohdpi.TrackerLoss`,** read from seven columns per eye: a blink where the pupil was not found (width or height 0) or `DataQuality` is below 100; a lost feature where P1 or P4 has a coordinate at 0; unreadable where any of the seven is not a finite number.
- **The validity mask takes the rule** in place of `DataQuality`: a blink is `blink`, a lost feature `invalid` (a new criterion, `feature_lost`), an unreadable frame `invalid` through `non_finite`. `EyeValidity` gains `frac_feature_lost`, and refuses in `populate()`, naming the `ALTER TABLE`, while the process reads a table without it.
- **`EyeQuality` counts by the same rule,** straight off the file: tracking loss is the share of frames lost or unreadable, and the blink rate counts runs of blink frames, runs under 100 ms apart as one.
- **Nothing else changes:** wl.works' contracts, the report's format, the NWB file.

**Tech Stack:** Python ≥3.11; numpy; pandas (`read_columns`); DataJoint 2.3.3 with MySQL.

**Spec:** `docs/superpowers/specs/2026-10-11-eye-loss-design.md` (`b2c9751`). It is binding. The requester approved the design in conversation on 2026-10-11, then the written spec (*"go"*). Task 4 adds its dated amendments, which record the rulings below.

**Every piece of code below was proven before this plan was written.** It was built on a scratch branch, `proof/eye-loss`, from `fix/eye-loss` at `b2c9751`, and then replayed from this plan's own text in a second worktree, which reproduced the proof's tree exactly.

Each is a dated amendment Task 4 adds to the spec.
- **1 (Task 2):** the stage refuses in `EyeValidity.populate()`, not in `make()`. A key whose `make()` raised is parked as an error and never retried (`daemon.reap_stale_jobs`), so the statement alone would not bring the stage back.

```python
"""Where the tracker lost the eye, read from what OpenIrisDPI actually writes
(design spec `2026-10-11-eye-loss-design.md` section 2).

`DataQuality` is 100 on every frame of the reference recording, blinks
included; a feature the plugin did not find is written as exactly 0. Every
test here builds the columns by hand, because the committed 200-row fixture
loses nothing and the synthetic generator never loses the eye."""

from pathlib import Path

import numpy as np

from wl_preproc.eye.ohdpi import read_tracker_loss, tracker_loss

FIXTURE = Path(__file__).parent.parent / "fixtures" / "ohdpi" / "OpenIris-sample.txt"

_NAMES = ("DataQuality", "PupilWidth", "PupilHeight", "CR1X", "CR1Y", "CR4X", "CR4Y")
# Typical values from the reference recording: nothing here is 0 or below 100.
_TRACKED = (100.0, 526.5, 112.3, 346.3, 289.8, 396.9, 196.8)


def _columns(n: int, eye: str = "Left") -> dict[str, np.ndarray]:
    return {f"{eye}{name}": np.full(n, value) for name, value in zip(_NAMES, _TRACKED)}


def _rows(mask: np.ndarray) -> list[int]:
    return [int(i) for i in np.flatnonzero(mask)]


def test_a_fully_tracked_frame_is_neither_lost_nor_unreadable():
    loss = tracker_loss(_columns(5), "Left")

    assert not loss.blink.any() and not loss.feature_lost.any() and not loss.unreadable.any()
    assert not loss.lost.any()


def test_a_pupil_not_found_is_a_blink():
    """The closed phase of every blink on the reference recording: the
    pupil's width and height read 0 while `DataQuality` stays 100."""
    columns = _columns(6)
    columns["LeftPupilWidth"][2] = 0.0
    columns["LeftPupilHeight"][4] = 0.0

    loss = tracker_loss(columns, "Left")

    assert _rows(loss.blink) == [2, 4]
    assert not loss.feature_lost.any()
    assert _rows(loss.lost) == [2, 4]


def test_data_quality_below_one_hundred_is_still_a_blink():
    """Kept for any tracker or version that does declare a failure."""
    columns = _columns(5)
    columns["LeftDataQuality"][1] = 50.0
    columns["LeftDataQuality"][3] = 0.0

    assert _rows(tracker_loss(columns, "Left").blink) == [1, 3]


def test_p1_or_p4_at_zero_is_a_lost_feature_not_a_blink():
    """P1 off the camera's view at upward gaze reads `CR1Y` 0 with the pupil
    still found: the gaze vector is not a position there, but the eye is
    open."""
    columns = _columns(8)
    columns["LeftCR1X"][1] = 0.0
    columns["LeftCR1Y"][3] = 0.0
    columns["LeftCR4X"][5] = 0.0
    columns["LeftCR4Y"][7] = 0.0

    loss = tracker_loss(columns, "Left")

    assert _rows(loss.feature_lost) == [1, 3, 5, 7]
    assert not loss.blink.any()
    assert _rows(loss.lost) == [1, 3, 5, 7]


def test_a_real_shaped_blink_is_a_blink_with_p1_lost_too():
    """As the reference recording has it: pupil and P1 at 0, P4 still
    reported, `DataQuality` 100."""
    columns = _columns(6)
    for name in ("PupilWidth", "PupilHeight", "CR1X", "CR1Y"):
        columns[f"Left{name}"][2:4] = 0.0

    loss = tracker_loss(columns, "Left")

    assert _rows(loss.blink) == [2, 3]
    assert _rows(loss.feature_lost) == [2, 3]
    assert _rows(loss.lost) == [2, 3]


def test_a_missing_value_is_unreadable_and_nothing_else():
    """A NaN compares false against both tests, so it is neither a blink nor
    a lost feature; it declares nothing, and the mask withholds it as
    `invalid` (as it withholds a missing quality flag)."""
    columns = _columns(len(_NAMES))
    for row, name in enumerate(_NAMES):
        columns[f"Left{name}"][row] = np.nan

    loss = tracker_loss(columns, "Left")

    assert _rows(loss.unreadable) == list(range(len(_NAMES)))
    assert not loss.blink.any() and not loss.feature_lost.any()


def test_the_two_eyes_columns_are_not_confused():
    columns = {**_columns(4, "Left"), **_columns(4, "Right")}
    columns["LeftPupilWidth"][0] = 0.0
    columns["RightCR1Y"][3] = 0.0

    left, right = tracker_loss(columns, "Left"), tracker_loss(columns, "Right")

    assert _rows(left.blink) == [0] and not left.feature_lost.any()
    assert _rows(right.feature_lost) == [3] and not right.blink.any()


def test_the_file_is_read_by_the_same_rule(tmp_path):
    """The seven columns per eye, read from a file in OpenIris's
    whitespace-separated shape; a column of another eye is not read."""
    columns = {**_columns(3, "Left"), **_columns(3, "Right")}
    columns["LeftPupilHeight"][1] = 0.0
    columns["RightCR4X"][2] = 0.0
    names = list(columns)
    path = tmp_path / "loss.txt"
    path.write_text(
        " ".join(names) + "\n"
        + "".join(" ".join(f"{columns[name][row]:.4f}" for name in names) + "\n" for row in range(3))
    )

    left, right = read_tracker_loss(path, "Left"), read_tracker_loss(path, "Right")

    assert _rows(left.blink) == [1] and not left.feature_lost.any()
    assert _rows(right.feature_lost) == [2] and not right.blink.any()


def test_the_real_fixture_loses_nothing():
    """The committed slice of a real recording: no 0 in any of the seven
    columns, and `DataQuality` 100 throughout (checked 2026-10-11)."""
    for eye in ("Left", "Right"):
        loss = read_tracker_loss(FIXTURE, eye)
        assert loss.blink.size == 200
        assert not loss.lost.any() and not loss.unreadable.any()

.venv/bin/python <<'PY'
import pathlib

s = s.rstrip("\n") + '''


# **What OpenIrisDPI writes for a feature it did not find: 0** (design spec
# `2026-10-11-eye-loss-design.md` section 1). Measured on the reference
# recording: `DataQuality` is 100 on every frame of both eyes, blinks
# included, while the pupil's width and height read 0 through the closed
# phase of every blink and P1's coordinates read 0 wherever P1 leaves the
# camera's view. A real position is fractional; the lowest 0.1% of P1's
# normal Y values sit at 69 px.
#
# `DataQuality` is 50*P1_valid + 50*P4_valid, so below 100 is still the
# tracker declaring a failure, on any version or tracker that sets it.
FULL_TRACKING_QUALITY = 100.0

_LOSS_COLUMNS = ("DataQuality", "PupilWidth", "PupilHeight", "CR1X", "CR1Y", "CR4X", "CR4Y")


@dataclass(frozen=True, slots=True)
class TrackerLoss:
    """Per frame, where the tracker lost one eye (design spec section 2).

    - `blink`: the pupil not found (its width or height 0), or `DataQuality`
      below 100.
    - `feature_lost`: P1 or P4 with a coordinate at exactly 0. Inside a blink
      P1 is lost too, so the two overlap there; P1 alone at 0 is the eye
      looking up, out of the camera's view of P1.
    - `unreadable`: a column read for this rule is not a finite number. A
      NaN compares false against both tests above, so such a frame is in
      neither: it declares nothing, and the validity mask withholds it as
      `invalid`, never as a blink.

    One rule for every consumer: the validity mask and `EyeQuality` both read
    it, so the mask's blinks and the report's blink rate cannot drift apart.
    """

    blink: np.ndarray
    feature_lost: np.ndarray
    unreadable: np.ndarray

    @property
    def lost(self) -> np.ndarray:
        """Either: the frames where the tracker lost the eye."""
        return self.blink | self.feature_lost


def tracker_loss(columns: Mapping[str, np.ndarray], eye: str) -> TrackerLoss:
    """The rule over one eye's columns, `eye` being `Left` or `Right`."""
    quality, width, height, p1x, p1y, p4x, p4y = (
        np.asarray(columns[f"{eye}{name}"], dtype=float) for name in _LOSS_COLUMNS
    )
    return TrackerLoss(
        blink=(width == 0) | (height == 0) | (quality < FULL_TRACKING_QUALITY),
        feature_lost=(p1x == 0) | (p1y == 0) | (p4x == 0) | (p4y == 0),
        unreadable=~np.isfinite(np.column_stack([quality, width, height, p1x, p1y, p4x, p4y])).all(axis=1),
    )


def read_tracker_loss(path: Path, eye: str) -> TrackerLoss:
    """The rule over one eye of the file at `path`: its seven columns, read
    in one pass."""
    return tracker_loss(read_columns(path, [f"{eye}{name}" for name in _LOSS_COLUMNS]), eye)
'''
p.write_text(s)
PY
```
