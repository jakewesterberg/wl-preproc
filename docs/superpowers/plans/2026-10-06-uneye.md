# U'n'Eye, the Seventh Detector, Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** register U'n'Eye as the seventh saccade detector, from its authors' own code and trained networks copied into this repository, running on the CPU with the network trained at the rig's rate as its default.

**Architecture:**
- **The copy** (Task 1): upstream's `uneye` package at `f97ca88` and its five two-class networks go to `wl_preproc/eye/vendor/uneye/`, with one import line changed and a `PROVENANCE.md`. The dependencies are declared: an optional `uneye` extra, `wl.yaml` entries, and CPU torch in CI.
- **The wrapper** (Task 2): `wl_preproc/eye/detect/uneye.py` adapts the network to the registry's `DetectFn`. It runs each usable stretch of 25 samples or more, always on the CPU, and gives each saccade the network's mean saccade probability as its reliability. torch is imported only when it runs.
- **Registration** (Task 3): `registry.DETECTORS["uneye"]`, vocabulary `{saccade}`. Every database test that ranges over the detectors takes it in. BMD's numba kernels move to numba's own thread pool, so torch's OpenMP runtime is the only one in a process.
- **The evidence** (Task 4): a test, gated on the Andersson dataset, pins why the default network was chosen.
- **The records** (Task 5): the addendum's amendments, the handoff, the checkpoint and the full suite.

**Tech Stack:** Python ≥3.11; PyTorch (CPU), through U'n'Eye's copied code; numpy; DataJoint 2.3 with MySQL; pytest.

**Spec:** `docs/superpowers/specs/2026-10-06-uneye-design.md` (`98d378d`), an addendum to `docs/superpowers/specs/2026-08-31-saccade-detection-design.md` §8. It is binding. The requester approved the design in two parts, then the written addendum (*"Approve, write the plan"*), on 2026-10-06. Task 5 adds its dated amendments 1–6, which record the rulings below.

**Every piece of code below was proven before this plan was written.** It was built on a scratch branch, `proof/uneye`, one commit per task, from `spec/uneye` at `98d378d`.
- **Each task's failing run** was measured on the previous task's code plus this task's tests.
- **Its passing runs** were measured on its own commit.
- **Every mutation check named here** was run against the final tree, and each failed its tests.
- **The full suite** was run on both interpreters with every task applied (Task 5 quotes it).
- **The plan replays exactly:** its commands and diffs, applied in order to `98d378d`, reproduce the proof's final tree.

## Global Constraints

- **The spec is binding,** including the dated amendments Task 5 adds. Where it and this plan disagree, the spec wins; record a ruling.
- **The copied code is never edited or reformatted** beyond the one import line `PROVENANCE.md` records; `test_uneye_copy.py` holds it to upstream's sha256.
- **The default network is `weights_dataset3`** (the requester's decision of 2026-10-06, amendment 1). Only the five two-class networks are copied; `weights_Andersson` is not.
- **U'n'Eye runs on the CPU** wherever it runs, and **importing the registry must not import torch.**
- **BMD's numba kernels run on numba's own thread pool (`workqueue`),** so torch's OpenMP runtime is the only one in a process (amendment 6). Never set `KMP_DUPLICATE_LIB_OK`.
- **Never commit** the OpenIris reference recording, the Andersson dataset, or the NSLR/BMD reference code, data or tables.
- **Leave the stray symlink `wl-preproc` at the repository root alone,** and keep it out of commits.
- **The environments** need U'n'Eye's libraries before Task 1's tests run (Task 1, step 1). The 3.11 venv already has torch, scikit-learn and matplotlib, through kilosort and remodnav.
- **Tests.**
  - Run with `.venv/bin/python -m pytest <files> -q -p no:cacheprovider` from the repository root. In a git worktree, prefix `PYTHONPATH=$PWD`.
  - Database tests need Docker (OrbStack on this machine: `open -a OrbStack` after a reboot). A module-wide setup error on a 120 s container timeout is the known flake: re-run it.
  - Mutation checks:
    - clear `__pycache__` first, and again after restoring;
    - run with `PYTHONDONTWRITEBYTECODE=1`;
    - make one mutation at a time, and restore the file afterwards.
  - **Run each task's own test files.** The full suite runs once, on both interpreters, in Task 5.
  - The shell is zsh:
    - an unquoted `$VAR` holding several arguments is not split;
    - a pipe through `tail` or `grep` hides the test command's exit status, so gate on the command's own status.
- **`wl-check` after `wl.yaml` changes** (Tasks 1 and 5).
- **Every commit message ends with** the trailer lines the harness gives the executing session.
- **Date what Task 5 records** (the checkpoint's and `wl.yaml`'s lines, the handoff) with the day the plan is executed; this plan proved them on 2026-10-06.

## Review Focus

Five inputs the spec implies, most likely first. Each is pinned by a test named here, in the task that owns the code.

1. **A machine where numba finds an OpenMP runtime of its own** (an Anaconda-based Python, as this machine's 3.13 venv): BMD and then U'n'Eye in one process, as the daemon runs them, must finish. Task 3: `test_bmd_leaves_torch_the_only_openmp_runtime`.
2. **A machine that never runs detection, without torch,** imports the registry (every CLI command does): it must still import. Task 3: `test_the_registry_imports_without_torch`.
3. **The preprocessing server reports its Pascal GPU:** U'n'Eye must stay on the CPU and not call `.cuda()`. Task 2: `test_the_network_stays_on_the_cpu_when_a_gpu_is_reported`.
4. **A blinky recording whose usable stretches are all under 25 samples:** no saccades and no error, since U'n'Eye itself refuses such input. Task 2: `test_a_piece_under_25_samples_is_not_run_through_the_network`.
5. **NaN gaze in a stretch the mask offers:** withheld, and the stretch split there. Task 2: `test_non_finite_gaze_is_withheld_where_the_mask_offers_it`.

## The rulings this plan carries

Each is a dated amendment Task 5 adds to the addendum.
- **1 (Task 2), the requester's decision of 2026-10-06: the default network is `weights_dataset3`.**
  - At the rig's 500 Hz, `weights_1+2+3` found 57 of 120 synthetic saccades of 5–15 deg and 71% of the Andersson coders' saccades.
  - `weights_dataset3` found 120 of 120 and 98%, at the cost of more extra detections.
- **2 (Task 1): `wl.yaml`'s entries have no `where`.** wl-orchestrator's `stack_for` gives an entry with `where` only to the machine classes it names, and the test suite runs U'n'Eye on the workstations this package builds on.
- **3 (Task 4): a validation test on the Andersson recordings,** since the default rests on them.
- **4 (Task 3): the planted-step database test allows U'n'Eye's fixational wobble** under 0.2 deg, while holding it to every planted step. It found each within 1 sample, and reported one 0.10 deg event during a hold.
- **5: torch was measured at 2.13.0 on 3.11 and 2.14.1 on 3.13,** with identical results.
- **6 (Task 3): BMD's numba kernels run on numba's own thread pool.** With a second OpenMP runtime beside torch's, U'n'Eye's first convolution waits forever; the proof's 3.13 suite hung seven hours on it. BMD's results cannot change: each kernel computes every sample on its own.

+"""Synthetic gaze for U'n'Eye's tests: saccades of stated amplitudes, with
+known onsets, between fixations (design spec `2026-10-06-uneye-design.md`
+section 5)."""
+
+from __future__ import annotations
+
+import numpy as np
+
+#: The reference recording's rate (saccade-detection design spec section 5).
+FS_HZ = 498.55
+
+
+def planted(amplitudes_deg, fs_hz: float = FS_HZ, seed: int = 0) -> tuple[np.ndarray, list[int]]:
+    """Gaze in degrees, `(n, 2)`, and each saccade's first sample.
+
+    One saccade per amplitude, in order, each in a random direction, turned
+    back toward the centre where it would pass 8 deg. Each lasts its
+    main-sequence duration, `2.2 * amplitude + 21` ms, with a raised-cosine
+    profile, between 0.3-0.6 s fixations. 0.01 deg of noise on everything."""
+    rng = np.random.default_rng(seed)
+    pieces, onsets, position, t = [], [], np.zeros(2), 0
+    for amplitude in amplitudes_deg:
+        hold = int(rng.integers(int(0.3 * fs_hz), int(0.6 * fs_hz)))
+        pieces.append(np.tile(position, (hold, 1)))
+        t += hold
+        angle = rng.uniform(0, 2 * np.pi)
+        step = amplitude * np.array([np.cos(angle), np.sin(angle)])
+        if np.hypot(*(position + step)) > 8:
+            step = -step
+        samples = max(2, int(round((2.2 * amplitude + 21) * fs_hz / 1000)))
+        profile = 0.5 - 0.5 * np.cos(np.linspace(0, np.pi, samples))
+        pieces.append(position + np.outer(profile, step))
+        onsets.append(t)
+        t += samples
+        position = position + step
+    tail = int(0.5 * fs_hz)
+    pieces.append(np.tile(position, (tail, 1)))
+    gaze = np.concatenate(pieces) + rng.normal(0, 0.01, (t + tail, 2))
+    return gaze, onsets
+
+
+def all_usable(n: int) -> np.ndarray:
+    """A validity mask offering every sample."""
+    return np.full(n, None, dtype=object)

+      produced a row.
+    - `min_saccade_duration_ms`: U'n'Eye's `min_sacc_dur`. The name is the

+

+

+    min_saccade_duration_ms: int
+    min_saccade_gap_ms: int
+
+    def __post_init__(self) -> None:
+        if self.weights not in NETWORKS:
+            raise ValueError(f"U'n'Eye has no network {self.weights!r}; have {list(NETWORKS)}")

+    here, not at the top: importing the registry must not need it."""
+    from wl_preproc.eye.vendor.uneye.classifier import DNN
+

+                  min_sacc_dist=params.min_saccade_gap_ms, min_sacc_dur=params.min_saccade_duration_ms)
+    # U'n'Eye moves itself to a GPU whenever torch reports one. On the
+    # preprocessing server that could be the Pascal card through a build
+    # that cannot run on it, and anywhere it would make a row depend on the
+    # machine (design spec section 3).
+    network.use_gpu = False
+    return network
+

+def detect_uneye(
+    gaze_deg: np.ndarray,
+    velocity_deg_s: np.ndarray,
+    available: np.ndarray,
+    fs_hz: float,
+    params: UneyeParams,
+) -> list[Run]:
+    """U'n'Eye, as the registered `DetectFn`: its `saccade` runs, half-open,
+    sorted, each with its reliability (design spec section 3).
+
+    - **The mask splits pieces,** as it does for NSLR: every maximal
+      stretch the validity mask offers is run through the network on its
+      own, so no detection spans a blink or invalid stretch.

+                            reliability=float(np.mean(probability[1, start:end]))))
