# Part 3b-3: a sync box that recorded part of the session

When the sync box stops partway, the NI keeps time (3b-1). Until this part the box's files, the eye tracker's and
the cameras' had no way onto that clock, so such a session was tier D (amendment 51). Part 3b-3 places them
through the NI's own barcodes, over the part the box covered, and checks the box's codes there against the NI's.
Such a session can be tier N. It is the last of three branches under part 3b. An NI restart is 3c, and the eye
tracker placed by its analog copy on the NI is the next piece (amendment 65).
- **Spec:** `docs/superpowers/specs/2026-10-18-training-records-and-backup-clock-design.md`, amendments 54-65 (the
  design), amendments 66-76 (made while planning and building). Where 66-76 differ from 54-64, they bind.
- **Plan:** `docs/superpowers/plans/2026-11-20-part-3b-3-partial-sync-box.md`, eight tasks, built by subagents.
- **Branch:** `feat/part-3b-3`, from `plan/part-3b-3` (`8d762d1`, the plan), from `spec/part-3b-3` (`d4b67b6`), from
  `main` at `c31dd89`.

## What was built

By amendment, each with its commits.
- **The synthetic box can stop** (decision 4 of amendment 66; Task 1, `debe5e2`). `SessionRecipe.syncbox_stop_s`,
  None by default, so every earlier recipe is unchanged. `synth/timeline.py` emits no barcode from the stop on, and
  `synth/syncbox.py::write_syncbox_log` writes only the records before it, with no trailer, as a Pi that lost power
  leaves it.
- **62, an end code reaches the end only where it ends the log** (Task 2, `0a26c6c`). `timebase/holding.py::_ending`
  finds whether `SESSION_END` is the last decoded code, with only `BLOCK_END` or `RUN_END` after it, and
  `unreached_end` reads it. `timebase/clock.py::CHOICE_RULES` is `"3b-3"`. The residual is amendment 75.
- **54-55, the NI's own barcodes are the reference, and the span** (Task 3, `65ad8db`). Under the NI,
  `Clock.barcode_reference()` returns the first NI file's gap-clear barcodes (`timebase/clock.py::ni_barcodes`,
  cached by file in `_ni_barcodes`). `Clock.covered_span()` is their first and last, or None.
- **56-57 and 60-61, the systems carrying barcodes, fitted under the NI** (Task 4, `3881f7e`, `f4f25b8`).
  - `schema/timebase.py::SystemTimebase.make`: under the NI, `_BY_THE_NIS_BARCODES` (the sync box, `ohdpi`,
    `bcam`) take today's barcode path against the NI's reference, with `time_source` `barcode`. With an empty
    reference they are `unfittable` with `none`, as in 3b-1 (decision 2).
  - `schema/core.py::Segment.make`: a file that decoded barcodes, none of them in the reference, is rejected as
    `timebase/segments.py::OUTSIDE_COVERED_SPAN`.
  - `TimingProvenance.make`: such a file, and a system whose every file is such, do not fail the session
    (`left_out`, which also needs the fit's `time_source` to be `barcode`). The box's losses are not asked to fail
    the timing check under the NI (60). `syncbox_fitted` needs `clock.source == "syncbox"` (61). The span is stored
    as `covered_start_s` / `covered_end_s` (decision 1).
- **59, the cross-check** (Task 5, `a440d52`, `01f7918`). `events/agreement.py::code_containment`, on the matcher
  shared with `code_agreement` (`_fraction_matched`). `schema/timebase.py::_box_cross_check` cuts both streams
  (amendment 69). Under the NI, `TimingProvenance` stores the containment as `event_code_agreement`, with
  `n_full_code_records` 2, and a value below `AGREEMENT_THRESHOLD` makes the session D. `SPLIT_CLOCK_PPM` and
  `ONE_RATE_TIMEBASES` moved from `cli/report.py` to `timebase/segments.py`.
- **58, eye data only inside the span** (Task 6, `d9f2e49`, `d0bfcba`).
  - `eye/span.py` is the one statement of "inside": `inside_span`, `rows_inside`, `clip_to_span`.
  - `schema/eye.py::placed_rows` gives the rows inside. `EyeCalibration` drops a window not wholly inside, and
    refuses, naming the span, where none is (amendment 70). `EyeQuality` counts frames and blinks inside only.
  - `schema/detect.py::EyeValidity` builds the mask over the rows inside, and stores every row outside as
    `invalid` (amendment 72). `EyeDetection` repairs, takes velocities and detects over the rows inside alone, and
    places its runs back among the recording's rows (`_repaired_gaze`, `_inside`, `_gaps_inside`, `_loss_inside`).
  - The main sequence is unchanged: it takes its saccades from `EyeDetection`.
  - `schema/coverage.py::_extents`: coverage stops at the span (amendment 68).
- **63, the NWB file** (Task 7, `185b25d`, `6b35b6b`).
  - `nwb/timebase.py`: `system_clocks.time_source` gains `barcode`, and the four NI texts say what a system the NI's
    barcodes placed holds. A sync-box file's texts are unchanged.
  - `nwb/gather.py::_eye`: samples, mask stretches, repairs, sources and detector events are cut to the span.
  - `nwb/gather.py::_span_notes` writes the notes of amendment 71 into `Gathered.span_notes`, which
    `nwb/describe.py` appends to the description's `notes`.
- **64, the tests.** `tests/schema/test_partial_sync_box.py` lands thirteen synthetic sessions in one module
  fixture: `partial`, `before_ni`, `dead_ni_line`, `synced`, `dead_cable`, `box_loss`, `disagree`, `last_trial`,
  `edge_loss`, `eyes`, `synced_eyes`, `late_eyes` and `camera_only`. Also `tests/timebase/test_ni_reference.py`,
  `tests/eye/test_span.py`, `tests/synth/test_syncbox_stop.py`, and new cases in `test_holding.py` and
  `test_agreement.py`.
- **Task 8: these records.** Amendments 66-76, tier N's and `outside_covered_span`'s lines in
  `docs/ops/lab-host-protocol.md`, two lines in wl.works' NI entry in `docs/pending-wl-works-amendments.md`, and
  this handoff.

## Rulings and choices

Each with what it costs if wrong. The ledger, `.superpowers/sdd/2026-11-20-part-3b-3-partial-sync-box/progress.md`,
holds the full wording. The plan's five decisions are in amendment 66.
- **P1, pre-flight, Task 4:** `before_ni` must hold a camera file with no barcode inside the span. Cost if wrong:
  the test would not exercise `outside_covered_span`.
- **R1, Task 4:** an eye or camera segment's offset is held to one frame period (2 ms at 500 Hz), not 100 µs. A
  500 Hz device's barcode edges are quantized to its frames (spec §3.1). The sync box is still held to 100 µs.
  Cost if wrong: none; the test's tolerance, not the code.
- **R2:** `before_ni`'s NI starts 0.5 ms after the box's first barcode, and its camera stops at 1.1 s, so its only
  barcode precedes the NI's first sample. P1's construction could not reach tier N. The NI loses its
  `SESSION_START` word, which amendment 44 allows. Cost if wrong: none.
- **R3:** amendment 64's camera line contradicts amendment 57. The code follows 57; amendment 67 corrects 64. Cost
  if wrong: none.
- **R4:** Task 4's review I1 entered a fix round: a `dead_cable` session (a camera's barcode line zeroed under a
  nonempty reference) is `no_barcode`, not left out, and tier D. M1 was folded in: `left_out` also needs the fit's
  `time_source` to be `barcode`. Cost if wrong: none.
- **R5:** Task 4's review I2 went to Task 6. Coverage of a system the NI's barcodes placed is cut to the span
  (amendment 68). Cost if wrong: a run past the span reads its eye coverage as missing, which it is.
- **R6, Task 5:** the loss-window cut is kept as amendment 59 says, though on an honest box it cannot change the
  value. Cost if wrong: none; the cut is defensive.
- **R7:** Task 4's two `partial` assertions (`n_full_code_records == 1`, agreement None) were removed. Task 5 makes
  them false; amendment 61 is guarded by the disagreement test instead. Cost if wrong: none.
- **R8:** fixes Task 5's review I1 and revises decision 3. The NI's stream is cut to the span's NI times, widened by
  0.5 s, and further on a box whose timebase is not one-rate (amendment 69). Cost if wrong: on a 12 h split clock
  the margin grows by about 2 s, which leaves about one trial at the end unchecked.
- **R9:** only path-W loss windows cut the box's part. Cost if wrong: none; under R6 the value cannot change on an
  honest box.
- **R10, Task 6:** where calibration windows existed and none lies inside the span, calibration is refused with a
  reason naming the span (amendment 70). Cost if wrong: one more refusal string.
- **R11, Task 7:** the stretch before the span is named in every partial-box file. It is true, and a file that left
  out data without saying so is the worse failure. Cost if wrong: one routine sentence per file.
- **R12:** a partial-box file states the covered span whenever `covered_start_s` is set, so a file with a camera
  and no eye tracker states it too (amendment 71). Cost if wrong: one sentence.
- **R13, Task 8:** the spec's new section records the build's rulings and the ledger's notes as well as the plan's
  decisions. A spec that omits them would mislead its next reader. Cost if wrong: a longer section.
